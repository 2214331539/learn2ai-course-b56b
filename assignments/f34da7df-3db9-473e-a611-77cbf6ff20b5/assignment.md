# 作业二：内容拆解与数据复盘

先阅读课程资料 `materials/04-发布与数据复盘.md`，本次作业不需要真的发布内容，重点是学会用数据拆解别人（或自己）的内容。

## 任务

1. **选一条内容**：挑一条你熟悉的、数据较好的新媒体内容（自己或他人的都可以），注明平台，并尽量写上它的公开数据（播放量、点赞、收藏等，查到多少写多少）。
2. **解释它为什么好**：用 `04` 的关键指标表，从完播率和互动率两个角度分析它靠什么留住观众，要求给出具体位置或细节（例如「第 2 秒抛出结论」「评论区引导了争论」）。
3. **提炼经验**：用 `04` 的复盘表格式，写出 3 条可迁移的经验，要求换成你自己的领域也能用。
4. **写改进计划**：回到作业一选定的选题，对照「发布前检查清单」，写出你在发布时会特别注意的 3 项，以及打算怎么执行。

## 交付要求

- 成果放在 `work/<你的用户UUID>/f34da7df-3db9-473e-a611-77cbf6ff20b5/` 目录下，建议用 `review.md` 保存。
- 每个结论都要有数据或具体细节支撑，避免「内容好所以火」这类空话。
- 完成后在应用里提交并确认分享本次学习过程。
