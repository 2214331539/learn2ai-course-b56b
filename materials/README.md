# 课程资料目录

本目录收录「测试新媒体」课程的讲义与模板，均为可直接用于练习的简化版本。

| 文件 | 内容 |
| --- | --- |
| `01-平台与内容形态.md` | 各新媒体平台的推荐逻辑、内容形态与选择建议 |
| `02-选题与标题.md` | 选题来源、选题检查清单与标题撰写方法 |
| `03-短视频脚本模板.md` | 分镜脚本表与 30 秒短视频结构 |
| `04-发布与数据复盘.md` | 关键指标、发布清单与复盘表 |

## 使用建议

1. 先读 `01`，确定自己要练的平台与内容形态。
2. 用 `02` 产出 3～5 个选题，挑一个写标题。
3. 用 `03` 把选题写成脚本。
4. 发布后用 `04` 复盘一次数据。

资料修改后由应用自动同步到课程仓库，无需手动提交。
