# 02 选题与标题

选题决定内容的上限，标题决定内容能不能被点开。

## 选题的四个来源

| 来源 | 说明 | 例子 |
| --- | --- | --- |
| 热点 | 借势已有流量，时效性强 | 新政策、热播剧、突发事件 |
| 痛点 | 解决目标人群的具体困难 | “第一次租房要怎么谈价格” |
| 对比 | 用差异制造信息量 | “100 元和 1000 元的耳机差在哪” |
| 教程 | 提供可复制的步骤 | “3 步做出一份合格的简历” |

## 选题检查清单

- 目标人群能不能一句话说清？
- 看完能得到什么（知识 / 情绪 / 工具）？
- 我有没有独特的经验或素材？
- 现在做还有时效性吗？

四项里至少满足三项，才值得动手。

## 标题的三个基本公式

1. **数字 + 结果**：`只做 3 件事，我把完播率提到 40%`
2. **身份代入**：`刚工作的人，别急着买这套设备`
3. **悬念缺口**：`这条视频被限流，问题出在前 3 秒`

## 好标题 vs 标题党

| 好标题 | 标题党 |
| --- | --- |
| 承诺的内容正文一定会给 | 点开后发现内容与标题无关 |
| 具体、可验证 | 夸张、模糊、只靠情绪 |

标题党的短期点击高，长期会伤害账号权重和信任。

## 练习

围绕你选定的平台，写 5 个选题，各配 1 个标题。
