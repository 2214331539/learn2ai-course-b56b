# 04 发布与数据复盘

## 发布前检查清单

- 标题、封面、前 3 秒表达同一个主题。
- 字幕无错别字，音量正常。
- 话题标签 2～4 个，与内容真实相关。
- 发布时间匹配目标人群的活跃时段。
- 发布后 30 分钟内回复评论。

## 关键指标

| 指标 | 含义 | 说明 |
| --- | --- | --- |
| 播放量 | 被展示并播放的次数 | 受推荐量影响，参考即可 |
| 完播率 | 看完的人数比例 | 决定能否进入下一级流量池 |
| 互动率 | （点赞 + 评论 + 收藏 + 转发）/ 播放 | 反映内容是否被认可 |
| 转粉率 | 新增关注 / 播放 | 反映账号的长期价值 |

优先看**完播率**和**互动率**，播放量高但没有互动说明内容留不住人。
